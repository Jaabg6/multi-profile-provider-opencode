# @multi-profile-provider/core

Lower-level profile registry and runtime isolation services for Multi Profile Provider.

Most OpenCode users should not install this package directly. Start with the product setup flow:

```bash
npx @multi-profile-provider/opencode setup
```

Use `@multi-profile-provider/core` directly only when integrating the registry, profile service, or runtime binding logic into another package in this workspace.

See the repository root `README.md` and `docs/commands.md` for user-facing setup and command documentation.
